## Open finding

**P2 — CPPS is always zero for ordinary speech sample rates**
(`src/audio/processor.py:281`). The code constructs a Hz axis with `rfftfreq` but
searches it using 2–16.7 ms quefrency bounds. Both bounds become index 1, leaving
no peak-search interval. A one-second 200 Hz harmonic complex at 16 kHz reproduces
`0.0`. This finding is separate from the already documented need to calibrate
voice-quality coaching thresholds.

Repair is deferred because changing the axis alone would retain an inconsistent
forward-FFT magnitude and non-dB baseline under the CPPS label. The working stack
now prioritizes a coherent transform/axis/unit repair against a documented Praat
reference, with deterministic waveform and reference-script comparisons.
