## Implemented features (baseline)

### Core backend & API infrastructure (`app/`)
- **FastAPI app & offline static serving** (`app/main.py`, `app/templates/index.html`, `scripts/build_frontend_assets.cjs`): Public Starlette `Jinja2Templates` setup with autoescaping, local compiled Tailwind CSS 3.4.19 (`static/css/tailwind.min.css`), vendored Plotly 2.32.0 (`static/vendor/plotly-2.32.0/plotly.min.js`), SHA-256 asset manifest verification (`npm run assets:check`), and `GET /health`.
- **Process-local inference gate & cancellation ownership** (`app/services/concurrency.py`): Single-slot inference lock shared across `/api/analyze`, `/api/reference-animation`, and `/api/prosody-lab/analyze`; closes rejected coroutines cleanly on HTTP 503 busy responses and drains worker threads before releasing locks or deleting temporary uploads.
- **Discoverable SSE progress job registry** (`app/services/jobs.py`, `app/api/sse.py`, `static/js/analysis_progress.js`): Job reservation (`POST /api/analysis-jobs`), status polling (`GET /api/analysis-jobs/{job_id}`), and SSE streaming (`GET /api/progress/{job_id}`) with `Last-Event-ID` / `?after=N` bounded replay (64 events/job, 256 max jobs, 5-minute TTL), independent subscriber fan-out, and terminal event guarantees (`complete`, `failed`, `cancelled`, `expired`).
- **Audio upload & preprocessing boundary** (`app/utils/audio.py`, `static/js/audio_conversion.js`): Browser Web Audio API decoding and 16-bit PCM WAV encoding with guaranteed `AudioContext.close()` cleanup; server-side upload handling (`save_upload_to_temp`) with `ffmpeg` conversion fallback and partial-output cleanup on errors/timeouts; shared mono 16 kHz float32 tensor decoding (`load_audio_tensor`).
- **Atomic JSON persistence & settings APIs** (`app/services/atomic_json.py`, `app/services/state.py`, `app/api/settings.py`, `app/api/desktop_history.py`): Crash-safe temp-file + `fsync` + `os.replace` persistence (`write_json_atomic`) using shared app-data path resolution (`state.data_file`) and `state.STATE_LOCK` locking for user settings (`PUT /api/settings`) and desktop Prosody Lab history (`PUT /api/desktop-history`).

### Speech, articulatory & prosody pipeline (`src/`)
- **ContentVec-L7 + frozen R4 streaming predictor** (`src/models/ssl_aai_predictor.py`, `src/models/r4_decoder.py`, `src/services/model_cache.py`): Local-only ContentVec 7-layer encoder + R4 `bounded_v12` temporal convolution decoder with `V12LatTemporalExtensionHead` predicting 9 tract variables (`LP, LA, TTCL, TTCD, TBCL, TBCD, VEL, GLO, LAT`) at 50 Hz over fixed 19,200-sample windows, 1,600-sample hops, and 1,600-sample lookahead, with lock-protected lazy singleton loading and asset-revision cache identities.
- **Coupled R4 contact head & hysteresis tracker** (`src/models/r4_contact.py`): Optional `R4ContactHead` (`weights/contact.pt`) with hysteresis `ContactTracker` for enhanced tongue-palate closure estimation, toggleable from Settings.
- **Canonical 9-field articulatory adapter & calibration** (`src/models/aai_adapter.py`, `src/models/articulatory.py`, `src/models/articulatory_calibration.py`): Named-field mapping from model outputs (`speaker_z_normalized`, `robust_01`, `z_score`, `raw`) to the canonical `0..1` 9-field renderer contract, monotonic global calibration (`identity`, `gamma`, `piecewise_linear`), IPA template/`pyclts` BIPA mapper, and HTML-escaped `POST /api/select-error` endpoint.
- **Parselmouth/Praat prosody & voice quality analysis** (`src/audio/processor.py`, `app/api/analyze.py`): Mono-preserving `AudioContext` and `ProsodyAnalyzer` extracting F0 contour (`mean_f0`, `f0_range`, `std_f0`, `range_semitones`), rhythm (`nPVI` returning `None` unless valid vowel timestamps exist), word stress prominence, Praat-backed `PowerCepstrogram: Get CPPS` (`cpps` in dB using Maryn & Weenink 2015 settings), and heuristic `jitter_local`, `shimmer_local`, and `spectral_tilt`, with partial-result fallback when SSL inference fails or model assets are absent.
- **Reference TTS & synchronized comparison cache** (`src/audio/reference_tts.py`, `src/services/comparison_cache.py`, `app/api/comparison.py`): `OmniVoiceTTSProvider` invoking local `omnivoice-tts` (8 kHz mono OGG Vorbis) and thread-safe `ComparisonCache` (LRU, TTL, per-instance file namespace, deep-copied snapshots) keyed by exact text, provider settings, and model file `stat` revisions (`POST /api/reference-animation`, `GET /api/comparison-cache/stats`, `DELETE /api/comparison-cache`).
- **Prosody Lab hybrid P-center analyzer** (`src/audio/prosody_lab.py`, `app/api/prosody_lab.py`, `app/models/schemas.py`): Standalone short-sample analysis (`POST /api/prosody-lab/analyze`) combining MIDI-quantized pitch tracks, `hybrid_acoustic_pcenter` syllable nucleus & perceptual-center ($V_{\text{onset}}$ / $C_{\text{onset}}$) detection, vocalic nPVI, speech/articulation rates, and silent pauses.

### Frontend & visualizations (`static/js/`, `app/templates/index.html`)
- **SVG sagittal vocal-tract renderer** (`static/js/svg_articulatory_renderer.js`): Custom SVG renderer supporting all 9 canonical tract variables, split tongue-tip/body palate roof tracks, velic port geometry, glottal aperture triangle, lateral airflow wind icon, animated voicing waves, and anatomical highlight zones.
- **Main Analysis workflow & trajectory inspector** (`static/js/recorder.js`, `static/js/analysis_trajectory.js`, `static/js/ipa_tooltips.js`): Push-to-talk `IntercomRecorder` (hold button or F5) with live canvas waveform, 16 kHz mono WAV upload, file-upload fallback, SSE progress bar, XSS-safe error/partial-result display, interactive IPA hover tooltips, and post-analysis audio/SVG frame-by-frame trajectory scrubber.
- **Comparison Lab** (`static/js/comparison_lab.js`, `static/js/ssl_comparison_controller.js`, `static/js/comparison_timing.js`): Side-by-side Reference vs. Student SVG players with quiet-edge speech trimming (`measureSpeech` keeping 100 ms padding), opt-in pitch-preserving duration matching (`getDurationMatch` within `0.85x..1.15x`), linked/unlinked playheads, speed control (`0.25x..1.25x`), loop in/out regions, student recording playback, and generation-token concurrency safety across text edits, fetches, and async decodes.
- **Settings & microphone diagnostics** (`static/js/settings.js`, `static/js/microphone.js`): Microphone enable/disable toggle, device enumeration/refresh with cross-launch label fallback, 3-second local test recording with live RMS `<meter>` and playback, and R4 contact enhancement toggle.
- **Prosody Lab frontend & Speech Rhythm winners** (`static/js/prosody_lab.js`, `static/js/prosody_rhythm_views.js`, `static/js/prosody_history.js`, `app/templates/index.html`): 44.1 kHz push-to-talk capture, bounded 3-recording history (`localStorage` or `/api/desktop-history`), Teacher/Student comparison roles, multi-bar Plotly Musical Score chart, Goal 1 **VocAlign Elastic Tethers & Danielsen Beat Bins** (`renderVocAlignTetherDiagnosticSVG` with Polak 100% Foot-Budget strip and DTW normalization slider), and Goal 2 **Stationary 16-Slot Prosodic Flow Matrix** (`renderFlowMatrixTrainerSVG` with 2-Bar Call-and-Response loop, Stress-Foot Pillars, Pause Gates, Anacrusis Ramps, Pre-Beat Consonant Runways, and Parabolic Bouncing Ball).

### Standalone macOS desktop app & packaging (`src-tauri/`, `app/desktop_backend.py`, `scripts/`)
- **Tauri native macOS shell & backend lifecycle** (`src-tauri/src/main.rs`, `src-tauri/src/backend.rs`, `app/desktop_backend.py`, `static/js/tauri_controller.js`): Spawns frozen Python backend in an isolated process group on a dynamic loopback port with `0700` `ready.json` handshake, `/health` verification, parent-PID watchdog, same-origin/`TrustedHostMiddleware` protection, system tray menu, and clicker/keyboard bridge.
- **PyInstaller freezer, `.pkg` installer & smoke checks** (`scripts/build_desktop_backend.py`, `scripts/build_desktop_installer.py`, `scripts/smoke_desktop_backend.py`, `scripts/smoke_desktop_app.py`): Packages arm64 Python 3.12 backend, stages R4 and OmniVoice assets with `0644`/`0755` permissions and SHA-256 verification, codesigns, builds `.pkg` installer, and runs automated backend/app/offline Playwright checks (`tests/e2e/mocked/offlineAssets.spec.js`).
